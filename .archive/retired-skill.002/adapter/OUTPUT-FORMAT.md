# 适配层设计文档输出格式

当所有适配层设计完成后，按照以下格式输出设计文档：

```markdown
# 适配层设计文档：[项目名称]

## 适配器类型
[Web UI/REST API/GraphQL/CLI/Chat/VSCode扩展/消息队列]

## 输入适配器（Input Adapters）

### 适配器1：[适配器名称]
**职责**：[适配器的职责描述]

**接口契约**：
- 端点/命令：[接口定义]
- 输入格式：[请求/参数格式]
- 输出格式：[响应格式]

**调用的用例**：
- [用例1]
- [用例2]
- ...

**错误处理**：
- [错误类型1]：[如何处理和响应]
- [错误类型2]：[如何处理和响应]

**Intent**：[一句话描述适配器功能]

### 适配器2：[适配器名称]
...

## 输出适配器（Output Adapters）

### 适配器1：[适配器名称]
**职责**：[适配器的职责描述]

**实现的接口**：
- [数据层接口名称]

**技术实现**：
- 技术栈：[数据库/API/文件系统等]
- 连接配置：[配置说明]
- 错误处理：[如何处理外部依赖错误]

**Intent**：[一句话描述适配器功能]

### 适配器2：[适配器名称]
...

## DTO 设计

### DTO1：[DTO名称]
**用途**：[输入/输出]

**字段**：
- `fieldName`: `type` - [字段说明]
- ...

**转换规则**：
- 外部格式 → 内部格式：[转换逻辑]
- 验证规则：[验证逻辑]

### DTO2：[DTO名称]
...

## 交互流程

### 流程1：[流程名称]
**场景**：[什么情况下触发]

**步骤**：
1. 外部请求到达输入适配器
2. 适配器验证输入并转换为 DTO
3. 调用应用层用例
4. 应用层返回结果
5. 适配器转换结果为外部格式
6. 返回响应给外部

### 流程2：[流程名称]
...

## 数据转换

### 输入转换
**外部格式 → 应用层格式**：
- [转换规则1]
- [转换规则2]
- ...

### 输出转换
**应用层格式 → 外部格式**：
- [转换规则1]
- [转换规则2]
- ...

## 错误处理

### 错误类型1
**场景**：[什么情况下发生]
**映射规则**：[应用层错误 → 适配层错误]
**响应格式**：[如何返回给外部]
**恢复建议**：[如何引导用户恢复]

### 错误类型2
...

## 认证和授权

### 认证机制
[如何验证用户身份]

### 授权策略
[如何控制访问权限]

### Token 管理
[如何管理认证令牌]

## 性能优化

### 缓存策略
[是否需要缓存？缓存什么数据？]

### 限流策略
[如何防止滥用？]

### 批量处理
[是否支持批量操作？]

## 测试策略

### 单元测试
[如何测试适配器？]

### 集成测试
[如何测试适配层和应用层的集成？]

### Mock 策略
[如何 Mock 应用层依赖？]
```
