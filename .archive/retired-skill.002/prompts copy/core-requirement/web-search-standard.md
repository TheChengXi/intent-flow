## 搜索角度

至少选 **2 个角度**搜索，覆盖不同维度：

| 角度 | 搜索词模版 | 说明 |
|------|-----------|------|
| **行业方案** | `{主题} best practice / architecture / design pattern` | 看主流怎么做 |
| **踩坑实录** | `{主题} pitfalls / 踩坑 / lessons learned / 注意` | 看前人踩过什么坑 |
| **方案对比** | `{主题} vs / alternatives / comparison` | 看选型分歧 |
| **具体实现** | `{主题} implementation / example / tutorial / github` | 看落地细节 |

## 搜索执行

- 使用 `queries` 参数（多 queries），每个角度一条 query
- 每个 query 返回 3-5 条结果
- 中文 + 英文混合搜（国内方案用中文，开源/通用方案用英文）

## 深度

- **默认**：AI 摘要 + 来源链接即可
- **拉全文**（`fetch_content`）：仅当发现高度相关的方案，且需要了解细节时

## 结果处理

搜索结果直接作为**参考背景**提供给用户，不自动纳入需求文档。

AI 做一句话总结：
> "搜到了 XX 方案 / XX 踩坑经验，和你的需求方向XX相关，可以作为参考。"

让用户决定要不要深入看。
