# 架构设计文档输出格式

```markdown
# 架构设计文档：[项目名称]

## 能力 → 模块映射

| 核心能力 | 所属模块 | 层级 | 设计理由 |
|---------|---------|------|---------|
| [能力1] | [模块1] | [adapter/application/data] | [为什么放这层] |
| [能力2] | [模块2] | [adapter/application/data] | [为什么放这层] |

## 模块定义

### [模块1]
- **层级**：[adapter/application/data]
- **职责**：[一句话]
- **入口文件**：[预期入口文件路径]
- **依赖模块**：[依赖的模块]
- **被哪些模块依赖**：[依赖此模块的模块]

### [模块2]
...

## 关键接口说明

### [模块1] 对外接口
[描述模块对外暴露的关键接口/能力]

### [模块1] → [模块2] 依赖
[为什么这个方向的依赖成立]

## 非默认决策

仅记录与 CCD 默认三层架构不同的决策：

- [如果有] 为什么某个层被省略了
- [如果有] 为什么需要跨层逆向依赖（必须说明为什么默认方案不行）
```
