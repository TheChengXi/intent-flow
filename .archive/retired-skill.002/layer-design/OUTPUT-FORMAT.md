# 分层设计文档输出格式

```markdown
# 分层设计文档：[项目名称]

## 数据层（Data Layer）

### 实体

#### [实体1]
- **字段**：`field: type` - 说明（必填/可选）
- **关系**：与 [实体2] → [1:1/1:N/M:N]
- **验证规则**：[关键验证逻辑]

#### [实体2]
...

### 仓库接口

#### [实体1]Repository
- `create(entity): Entity` — 创建
- `findById(id): Entity | null` — 按 ID 查询
- `update(id, partial): Entity` — 更新
- `delete(id): void` — 删除

#### [自定义查询方法]
- `[方法签名]` — [说明]

## 应用层（Application Layer）

### 用例

#### [用例1]
- **职责**：[一句话]
- **前置条件**：[什么条件下可用]
- **后置条件**：[执行后的结果]
- **依赖仓库**：[依赖的数据层接口]
- **关键业务规则**：[核心逻辑]

#### [用例2]
...

## 适配层（Adapter Layer）

### 输入适配器

#### [适配器1]（[UI/API/CLI/Chat]）
- **入口**：[调用入口]
- **调用的用例**：[用例1]、[用例2]
- **输入格式**：[请求格式]
- **输出格式**：[响应格式]

### 输出适配器

#### [适配器1]（[数据库/外部API/文件系统]）
- **实现的接口**：[对应的仓库/服务接口]
- **技术选型**：[具体技术]
- **关键实现要点**：[连接/错误处理等]

## 数据流

### [关键流程1]
外部 → [适配器] → [用例] → [仓库] → 存储

### [关键流程2]
...
```
