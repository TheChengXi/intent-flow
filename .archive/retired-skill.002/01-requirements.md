# 需求文档：VSCode 能力地图插件

## 项目意图

提供一个 VSCode 自定义面板，将项目的 `@intent` 和依赖关系渲染为可视化的能力地图，支持人类直接在图上拉框分组调整，替代纯代码层的意图包管理。

## 用户群体

- **开发者**：可视化浏览项目模块结构，快速理解每个文件夹/文件在做什么
- **架构师**：手动调整能力分组，校准 LLM 聚类结果
- **LLM Agent**：通过插件提供的接口获取格式化后的能力地图数据

## 功能清单

1. **文件夹选择**：用户选择一个文件夹，插件调用 `ListFolderIntents` 获取该文件夹的意图清单
2. **图形渲染**：将数据渲染为三种图形节点 + 连线的可视化地图
3. **子文件夹导航**：点击三角形节点，再次调用 `ListFolderIntents` 渲染同层子文件夹的能力
4. **入口文件定位**：双击圆形节点，调用 `trace_dependency_chain` 以此为入口追踪依赖树
5. **手动分组调整**：拖拽、拉框，将方形节点归入圆形节点，调整能力分组
6. **意图查看**：鼠标悬浮任意节点，实时读取文件 `@intent` 并展示详情
7. **保存分组**：手动调整后的分组写入 `.cdd/packages/*.yml`

## 图形元素定义

| 图形 | 代表 | 数据来源 | 交互 |
|------|------|---------|------|
| △ 三角形 | 子文件夹 | `ListFolderIntents.subdirectories` | 点击 → 递归调用 ListFolderIntents 渲染同层能力 |
| ⭕ 圆形 | 组合能力（一组文件） | `IntentPackage.groups` | 双击 → 调用 `trace_dependency_chain`（默认第一个文件为入口） |
| ■ 方形 | 元能力（单个文件） | `ListFolderIntents.files` | 预留交互接口（当前无行为） |
| → 箭头 | 依赖关系 | `ImportExtractor` 采集的同层引用 | 预留交互接口（当前无行为） |

## 业务规则

### 实时读取与缓存

- **场景**：用户悬浮/点击节点查看 @intent 详情
- **行为**：优先读取文件系统获取最新的 `@intent` 内容；如果文件未变更，读取缓存
- **异常处理**：文件读取失败时显示「无法读取」，不中断面板渲染

### 手动分组保存

- **场景**：用户拖拽方形节点归入圆形节点，或拉框选择多个节点创建新圆形
- **行为**：更新内存中的分组结构，用户点击保存后写入 `.cdd/packages/*.yml`
- **格式**：与现有 `IntentPackage` 结构一致（packageName / summary / groups / crossRefs）

### 子文件夹导航

- **场景**：用户点击三角形节点
- **行为**：以该子文件夹路径为参数调用 `ListFolderIntents`，面板跳转到该层的能力地图
- **边界**：子文件夹没有文件时显示空状态提示

### 入口文件定位

- **场景**：用户双击圆形节点（组合能力）
- **行为**：取该组的第一个文件作为入口，调用 `trace_dependency_chain`，结果在侧边或新面板展示
- **边界**：组内无文件时无响应

## 非功能需求

- **实时性**：@intent 详情悬浮查看时直接读文件系统，不当缓存懒加载
- **数据一致性**：手动分组保存与现有 `.cdd/packages/*.yml` 格式完全兼容
- **低侵入**：插件不修改 `ListFolderIntents` / `ImportExtractor` 等现有元能力代码，只消费它们的输出
