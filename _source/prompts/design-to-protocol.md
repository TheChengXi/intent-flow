# 转换规则：pencil 设计稿 → 组件协议

以下规则具有最高优先级。

将已画好的 .pen 设计稿转换为项目业务所需的组件和页面规则（百分比 + token），存放到相应位置。转换 = 提取 + 存放。

## 提取

1. 用 pencil MCP 的 Get 全量读节点（含 geometry 与 metadata），不直接读 .pen 原文；操作前确认目标文件在编辑器中打开（活跃文件）
2. 画板 frame 尺寸 = 根基准锚点，缺失则拒绝转换
3. 读 context / metadata：组件角色（role）、状态变体（state）、数据区（data-slot）以标注为直接依据；标注缺失时按存放侧第 11/13/14 条判断，无法判断 → 返回问题清单
4. 读 variables，已有的 $ 引用原样保留

## 存放

5. 百分比 = px ÷ 直接父组件宽高（父组件为准，6 位小数）；left 参照宽、top 参照高
6. 动态尺寸：fit_content → auto；fill_container → 100%
7. 固定小值（描边宽等）不进百分比
8. 盒模型 → 百分比；形状 geometry 原样透传，viewBox 按 geometry 紧包围盒推导（非节点尺寸）
9. name → identity（kebab-case 路径式命名，层级对应组件/子组件）
10. 颜色/字号/间距复用 ≥2 次 → token（语义命名如 text-primary，非 raw hex），否则保留原值；间距按刻度归并（4px 网格），不发明任意值
11. 重复出现 / 独立职责 / 数据占位边界 → 切为组件；页面先切组件再逐个转；组件职责膨胀（过大）继续拆；切出的组件标角色：容器型（管数据/状态）vs 展示型（管渲染）
12. 组合优于配置：从设计稿取出的组件已组合完成——保持 slots 组合结构，不拍平成配置式 props
13. 数据区与交互点 → 只做占位声明（文本写占位符，UI 固有文字写本体）；状态按归属分层标注：组件内状态（不标）/ 2-3 兄弟共享（父级占位）/ 全局（Context/Store 占位）/ 服务端数据（数据源引用）/ URL 状态（页面级占位）；避免超过 3 层嵌套传递
14. 设计稿含状态变体（loading / empty / error）时按变体提取并标记，画了什么提什么
15. 切出的组件根坐标（相对父节点）丢弃，根基准由观察/嵌入环境提供
16. colocate：组件相关产物（协议定义/占位/换算）同一目录组织，identity 路径式对应目录层级
17. 页面规则独立存放：响应式断点（320/768/1024/1440）、布局模式等页面级信息不塞进组件内部

## 验证

18. 转换完成后全量跑通：整个页面实际运行效果测试（console 无错 / 键盘可访问 / 响应式断点表现 / 三态处理 / token 一致），对照 frontend-ui-engineering 的 Verification 清单；误差 <0.5px、比例 <0.1%；等待反馈确认
