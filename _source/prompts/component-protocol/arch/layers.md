# 分层架构

协议描述两层核心职责，其余部分由实现者自定。

## 核心两层

```
┌──────────────────────────────────────────────┐
│         ① 协议定义层                          │
│  组件树 + 百分比尺寸 + 行为契约 + 数据契约     │
│  只写 % / @text / @image，不出现 px / hex     │
├──────────────────────────────────────────────┤
│         ② 换算层（Converter）                  │
│  纯函数，协议 % CSS → 运行时 px 坐标           │
│  框架无关 / 协议无关 / 输入相同输出一定相同    │
│  50-80 行纯数学，任何语言可独立实现            │
└──────────────────────────────────────────────┘
```

### 协议定义层

协议节点只含百分比尺寸、token 颜色引用、资源引用。不出现 px、不出现 hex。

```
组件 protocol.ts:
  width: '8%'                         ← %
  fill: '@token.primary'              ← token 引用
  label: '@text.dialog.confirm'       ← 资源引用
```

### 换算层

Converter 将协议定义的百分比换算为运行时 px 坐标。纯函数，不依赖任何框架。

```
protocol.ts（8% / 10%）
    ↓ compileNode
{ ratioWidth: 0.08, ratioHeight: 0.10 }
    ↓ convertTree(compiled, cw=1000, ch=600)
{ w: 80, h: 60, left: ..., top: ... }  ← 全是 px
    ↓
render 消费 px，不需要知道百分比存在
```

## 其他层（实现者自定）

协议定义层和换算层之外的职责——生命周期管理、状态调度、数据计算、渲染绘制——由实现者按项目需要自行决定。协议不强加任何运行时结构。

常见选项：

| 职责 | 可选方案 |
|------|---------|
| 生命周期 / 页面编排 | Vue / React / Svelte / 游戏主循环 / 纯 TS |
| 状态管理 | reactive / Redux / Zustand / 手工状态表 |
| 渲染绘制 | Canvas / DOM / SVG / Three.js / SDL |
| 文本测量 | @chenglou/pretext / DOM measure / 自研排版 |

## 根节点容器尺寸

协议只定义"需要容器尺寸才能换算"，不规定容器来源。
- Web 应用：由 100% div + ResizeObserver 提供
- 游戏场景：由窗口系统或摄像机视口提供
- 命令行：由显式传入的 width / height 提供
