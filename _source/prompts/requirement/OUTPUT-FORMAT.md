# 需求文档输出格式

```markdown
# 需求文档：[项目/功能名称]

## 项目意图
[一句话描述核心目标]

## 用户群体
[目标用户是谁]

## 功能清单
1. **[功能1]**：[一句话描述]
2. **[功能2]**：[一句话描述]
（列出所有识别到的功能，不做核心/非核心区分）

## 业务规则

### [规则名称]
- **场景**：[什么情况下触发]
- **行为**：[系统如何响应]
- **异常处理**：[异常情况怎么处理]

## 非功能需求（如提到则记录）
- **性能要求**：[响应时间 / 并发量]
- **安全要求**：[认证 / 授权]
- **可用性要求**：[易用性]
```
