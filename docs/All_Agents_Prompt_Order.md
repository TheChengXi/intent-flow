# 所有 Agent 的提示词顺序分析

## 当前实现的 Agent

1. **CompilerVM** - 编译器（注释 → 代码）
2. **ReviewerVM** - 审查员（代码 + 注释 → 审查报告）
3. **CodeTranslatorVM** - 代码转译员（代码 → 更新注释）

---

## 1. CompilerVM（编译器）提示词顺序

### 当前顺序（❌ 有问题）

```
1. 系统提示（绝对稳定）
2. 重要规则（绝对稳定）
3. 函数契约（绝对稳定）
4. 引用的函数契约（较为稳定，❌ 未排序）
5. 审查反馈（最不稳定）
6. 增量编译信息（最不稳定）
7. 编码规范（❌ 位置不对，应该在前面）
```

### 问题

1. ❌ **引用契约未排序**（第 4 部分）
2. ❌ **编码规范位置不对**（第 7 部分）

### 修复后的顺序（✅ 正确）

```
1. 系统提示（绝对稳定）
2. 编码规范（绝对稳定）← 移到这里
3. 函数契约（绝对稳定）
4. 引用的函数契约（较为稳定，排序后）← 添加 .sort()
5. 审查反馈（最不稳定）
6. 增量编译信息（最不稳定）
```

---

## 2. ReviewerVM（审查员）提示词顺序

### 当前顺序（✅ 合理）

```
1. 契约（稳定）
2. 代码（不稳定）
3. 编码规范（稳定）
```

⚠️ **问题**: 使用 context 对象，属性顺序不保证

---

## 3. CodeTranslatorVM（代码转译员）提示词顺序

### 当前顺序（✅ 简单稳定）

```
1. 代码（不稳定）
2. 旧契约（稳定）
```

⚠️ **问题**: 使用 context 对象，属性顺序不保证

---

## 修复优先级

| Agent | 问题 | 优先级 |
|-------|------|--------|
| **CompilerVM** | 引用契约未排序 + 规范位置不对 | **P0** |
| **ReviewerVM** | context 对象顺序不保证 | **P1** |
| **CodeTranslatorVM** | context 对象顺序不保证 | **P2** |
